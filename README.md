# 日期计数器 (Day Counter) v2.0

管理和追踪重要日子的单文件 PWA 工具。

## 🆕 v2.0 更新

- 新增 **多个倒计时管理**：添加 / 删除任意数量的事件，按临近程度自动排序
- 新增 **正数 / 倒数切换**：每张卡片可独立切换「还有 N 天」与「已过去 N 天」
- 新增 **分享卡片**：Canvas 生成精美图片，可保存 PNG 或复制文案
- 新增 **默认模式选择**：添加事件时可选默认倒数或正数
- 保留原「两日期间隔计算」功能，放入折叠面板
- 注入 SOLCAT 彩蛋引擎，UI 全面美化

## 功能

- **事件管理**：名称 + 日期 + emoji，本地持久化
- **智能排序**：按与目标日期的距离由近到远排列，已过事件灰显
- **准确天数**：用 `Date.UTC()` 归一化，避免夏令时导致的小数天
- **分享卡片**：渐变背景 + 大数字 + 日期，一键保存或复制
- **间隔计算**：折合周 / 月 / 年，支持交换日期、设为今天
- **中英文切换**：界面文案同步切换

## 使用方法

1. 打开 `index.html`
2. 填写事件名称、日期与 emoji，点 `+` 添加
3. 点击卡片上的「倒数 / 正数」切换显示方向
4. 点「分享」生成卡片图片，保存或复制文案
5. 展开底部面板可使用原两日期间隔计算
